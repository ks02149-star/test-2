네이버 블로그를 운영하다보면 가끔 네이버 통계 데이터를 엑셀이나 아니면 다른 저장매체에 저장을 하고 싶을때가 있습니다. 이런 경우 파이썬을 활용하여 어떻게 네이버 블로그 조회수 순위를 엑셀로 저장할 수 있을지에 대해 알아보도록 하겠습니다.
​
네이버 블로그 통계
먼저 나의 네이버 블로그 조회수 순위는 네이버 블로그 통계 페이지에서 확인 할 수 있습니다.
위의 이미지에서 처럼 네이버 블로그 조회수 순위는 내 블로그의 관리자 페이지에서 내블로그 통계 메뉴를 통해 확인 할 수 있습니다. 그런데
이 페이지를 보기 위해서는 먼저 네이버에 로그인이 된 상태
여야 합니다. 그래서 이번 포스트에서는
지난 포스트에서 작성한 네이버 로그인 클래스
를 함께 활용하기로 합니다. 혹시나 못 보신 분들은
링크를 클릭
해서 언넝 보고 오시기 바랍니다.
​
네이버 블로그 조회수 순위 페이지 분석
일단 네이버 블로그 통계의 조회수 순위 페이지를 접속해서
상단의 날짜를 변경해보면 브라우저의 URL 이 변경되지 않는다는 사실
을 알 수 있습니다. 이렇게 브라우저의 URL 이 변경되지 않는 페이지는 지난 포스트에서도 얘기한적이 있지만 보통
자바스크립트로 처리를 하거나 아니면 IFRAME 으로 구성된 페이지인 경우 브라우저의 주소가 변경되지 않습니다
.
​
그런 경우 IFRAME 인지 자바스크립트인를 가장 빠르고 쉽게 확인하려면 위의 이미지에서 처럼 링크에서 마우스 우클릭을 하고 링크를 새창에서 혹은 새탭에서 열기를 해보면 알 수 있습니다.
​
네이버 블로그 통계 조회수 순위 페이지를
새탭으로 열어보았더니 브라우저 주소표시줄의 주소가 변경된것을 확인
할 수 있었습니다.
그러나 여기서도 날짜를 변경해보면 실제 브라우저의 주소가 변경되지는 않았습니다.
그럼 이제 브라우저의 개발자도구를 열어서 페이지 분석을 좀 더 해봐야 합니다.
​
브라우저의 개발자도구의 네트워크 탭을 열어놓은 상태에서 상단의 날짜를 변경해보면 우측의 네트워크 탭에 어떤 페이지가 요청되는 것을 확인할 수 있습니다. 이 말인 즉슨,
해당 페이지의 실제 데이터는 현재 페이지에서 Ajax 통신을 하여 내부적으로 데이터를 구해오고
구해온 데이터를 현재 보여지는 구성에 맞게 출력해주고 있다는 사실을 짐작해볼 수 있습니다.
​
개발자 도구의 네트워크 탭에서 ccContentPc?time... 으로 시작하는 주소의 항목을 클릭해보면 위의 이미지에서 처럼
https://blog.stat.naver.com/api/blog/rank/cvContentPc?timeDimention=DATE&startDate=2022-04-30&exclude=....
. 같은 API 주소로 데이터를 요청하고 있다는 사실을 알 수 있습니다.
​
이번에는 해당 페이지의 응답 데이터를 살펴보면 위의 이미지에서 처럼 우리에게 필요한 데이터가
JSON 형태
로 전달되고 있다는 사실을 알 수 있습니다.
​
해당 API 주소가 네이버 블로그 통계의 조회수 순위 데이터를 전달해주는 주소인것을 확인했으니 위의 이미지에서 처럼 해당 주소 항목에서 마우스 우클릭을 하여 새탭에서 열기를 하여 데이터의 구조를 좀 더 자세히 살펴봐야겠습니다.
​
참고로 모질라 파이어폭스 브라우저는 JSON  을 위 처럼 트리 형태로 표기해줍니다.
네이버 블로그 통계 조회수 순위 데이터는 이렇게 API 를 통해서 구해온다는 사실을 확인하였으니 이제
파이썬으로 이 주소를 접속하여 필요한 데이터를 수집
해보도록하겠습니다.
​
네이버 블로그 조회수 순위 파이썬 코드 작성
from naver import NaverLogin

NAVER_ID = "네이버아이디"
NAVER_PASS = "네이버비밀번호"

naver = NaverLogin(NAVER_ID, NAVER_PASS)

if not naver.login():
    print("네이버 로그인 실패")
    exit(0)

url = "https://blog.stat.naver.com/api/blog/rank/cvContentPc?timeDimension=DATE&startDate=2022-04-30"
r = naver.get(url)
j = r.json()
print(j)
이전 포스트에서 작성한 네이버 로그인 클래스
를 naver.py 파일에 저장하고 같은 경로에서 위의 내용을 작성한 파이썬 파일을 생성합니다. 그러면 위의 코드에서 처럼
from naver import NaverLogin
을 통해 이전 시간에 작성한 네이버 로그인 클래스를 모듈로 불러와 사용할 수 있게 됩니다.
만약 네이버 로그인이 실패한다면 프로그램을 종료하고 로그인에 성공한다면 위의 코드에서처럼 API 주소를 호출하여 결과를 JSON 형태로 읽어 출력해보는 샘플 코드 입니다.
​
코드를 실행하면 위의 이미지에서 처럼 우리가 분석한것과 똑같은 결과가 출력되는 것을 확인할 수 있습니다.
​
네이버 블로그 통계 조회수 순위의 실제 데이터는 JSON 데이터에서 result 의 자식노드인 statDataList -> data -> rows 에 속해 있습니다. 여기서 주의해야할 점은
statDataList 의 자료 형태는 리스트 형태
라는 점 입니다. 그럼 최상위 부모 노드서부터 목적지의 rows까지 순서대로 접근하여 자료를 읽어보도록 합니다.
from naver import NaverLogin

... 생략 ...

j = r.json()
if j.get("statusCode") == 200:
    items = j.get("result", {}).get("statDataList")[0].get("data", {}).get("rows")
    print(items)
위의 코드에서 처럼 자료의 형태를 주의하면서 최상위 노드인 results 노드서부터 자식노드로 내려갑니다.
​
코드를 실행해보면 마지막 자식노드의 rows 에 속한 date, cv, rank, title, uri, createDate 의 자료가 출력됨을 확인할 수 있습니다.
이 데이터들은 각각 리스트 형태의 자료형임을 또 주의
해야 합니다.
​

이제 위의 코드에서 처럼 각각 분리된 date, cv, rank, title, uri, createDate 를 구해서 이 전체를 사용하기 편하게
zip 함수로 묶어서 for 문으로 반복하며 하나의 데이터처럼 처리
할 수 있게 코드를 작성합니다.
​
코드를 실행해보면 위의 이미지에서 처럼 날짜, 조회수, 랭킹, 제목, 주소, 생성일자가 문제 없이 출력되는것을 확인했습니다.  이제 이 JSON 데이터를 엑셀에 저장하면 될것 같습니다. 역시나
이전 포스트에서 다룬 파이썬 엑셀 저장하기 편
을 참고하여 저장을 해봅니다.
​

🏳‍🌈파이썬 블로그 통계 조회수 순위 엑셀 저장 완성 코드
from naver import NaverLogin
import openpyxl
import datetime

NAVER_ID = "네이버아이디"
NAVER_PASS = "네이버비번"

naver = NaverLogin(NAVER_ID, NAVER_PASS)
if not naver.login():
    print("네이버 로그인 실패")
    exit(0)

filename = "네이버_블로그_통계_조회수_순위.xlsx"
wb = openpyxl.Workbook()

start_date = datetime.datetime(2022, 4, 1)
timedelta = datetime.timedelta(days=1)

for i in range(10):
    start_date += timedelta
    date_str = start_date.strftime("%Y-%m-%d")
    sheet = wb.create_sheet(title=date_str, index=0)

    url = f"https://blog.stat.naver.com/api/blog/rank/cvContentPc?timeDimension=DATE&startDate={date_str}"
    r = naver.get(url)
    j = r.json()
    if j.get("statusCode") == 200:
        items = j.get("result", {}).get("statDataList")[0].get("data", {}).get("rows")
        date = items.get("date")
        cv = items.get("cv")
        rank = items.get("rank")
        title = items.get("title")
        uri = items.get("uri")
        createDate = items.get("createDate")
        
        row = 1
        for d, c, r, t, u, e in zip(date, cv, rank, title, uri, createDate):
            print(d, c, r, t, u, e)
            sheet.cell(row, 1).value = r
            sheet.cell(row, 2).value = c
            sheet.cell(row, 3).value = t
            sheet.cell(row, 4).value = u
            sheet.cell(row, 5).value = e
            sheet.cell(row, 6).value = d
            row += 1

        sheet.column_dimensions["A"].width = 3
        sheet.column_dimensions["B"].width = 7
        sheet.column_dimensions["C"].width = 60
        sheet.column_dimensions["D"].width = 42
        sheet.column_dimensions["E"].width = 15
        sheet.column_dimensions["F"].width = 15

wb.save(filename)
파이썬 네이버 블로그 통계 조회수 순위 완성 코드는
2022년 4월 1일부터 11일까지 총 10일간의 데이터를 엑셀에 저장하는 코드 샘플
입니다. 날짜의 계산은 datetime 의 timedelta 를 이용해서 시작날짜부터 1일씩을 더해서 계산합니다.
만약 시작 날짜가 3월 31일이라면 1일을 더해 4월 1일을 구할 수 있습니다
.
​
위의 파이썬 완성 코드를 실행해보면 위의 이미지에서 처럼 10일간의 데이터가 각 시트별로 저장되게 됩니다.
​
🚩파이썬 도전 과제
지금까지 작성한 코드는 네이버 블로그의 통계중 조회수 순위 일간 데이터를 기준으로 작성한 코드 입니다. 만약 주간이나 월간 데이터를 기준으로 1년치의 데이터를 엑셀에 저장한다고 하면 어떻게 코드를 수정해야할지를 한번 생각해보는것도 좋은 공부가 될듯 합니다.
